## 宣传文案

- **推广文本（30 字内）**：把家务变成全家的游戏，每一分都是爱 🏠
- **描述首屏**：
  > 家分宝把洗碗、阅读、运动这些小事变成全家人的积分游戏：孩子打卡得分、家长评审通过、周榜见成长、商城换惊喜。
  >
  > - 🏠 五口之家一起上榜：日/周/月/年榜 + 进步榜（和自己比，不焦虑）
  > - 🛡️ 家长评审制：打卡可拍照凭证，通过才入账
  > - 🎁 积分商城：冰淇淋、零花钱、免家务券，支持限时折扣
  > - 🔒 纯本地数据，不收集任何个人信息
- **描述尾段**：核心功能永久免费；会员（¥18/月、¥128/年）解锁无限成员/永久历史/完整年报。

## 审核备注（Review Notes）

- 测试路径：欢迎页「先体验一下」进入演示家庭（王家五口、30 天数据），可完整体验打卡→评审→排行→兑换闭环
- 会员订阅：月 ¥18 / 年 ¥128，自动续订，可在系统设置取消
- 定位权限：仅用于"到家提醒待办"（可选功能），坐标只存本机
- 相机权限：仅用于任务凭证拍照（可选功能），照片不导出
